# Run the adventure in a browser IDE

You do not need to install Python. Open an online Python editor in your browser and paste the code from adventure.py into its editor.

## Run the game

1. Open any bowser python ide (for example: https://www.online-python.com/)
2. Select the example code in the editor and replace it with the full contents of adventure.py.
3. Click Run.
4. When the game asks a question, type your answer in the terminal and press Enter. The game pauses while it waits for each answer.
5. To play again, click Run again.

Keep the spaces before the print() lines inside if, elif, and else blocks. Those spaces show which story belongs to each choice.
